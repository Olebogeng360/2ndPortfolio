About

I'm Senwelo Olebogeng, a Full-Stack Developer and ICT student at Tshwane University of Technology. I specialise in building backend-first applications with Java and Spring Boot, and I pair them with clean, responsive front-ends using HTML, CSS, and JavaScript.

I care about writing code that is readable, testable, and ready to ship — whether that means a well-structured REST API, a containerised deployment pipeline, or a UI that gets out of the user's way. I'm currently deepening my understanding of cloud-native architecture on AWS and working toward stronger microservices patterns.

Outside the stack I hold a CCNA: Switching, Routing & Wireless Essentials certification, which gives me a solid grounding in how networks actually move data — context that shapes how I think about latency, connectivity, and infrastructure.
